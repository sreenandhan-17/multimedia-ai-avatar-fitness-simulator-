# Model files

- `avatar.glb` — the 3D avatar: female and male characters with one animation clip per
  exercise (clip names match `avatarClip` in `client/src/data/exercises.json`).
  Built by `blender/build_avatar.py`; see `blender/README.md`. Do not edit by hand.
- `pose_landmarker_lite.task` — the MediaPipe pose model used for live correction.
