# 3D Avatar Models Directory

Place your 3D GLB/GLTF models in this directory.

Default model expected by the application:
- `avatar.glb` (e.g., standard Ready Player Me, Mixamo, or custom rigged humanoid GLB model)

The Fitness Avatar Simulator will automatically load `/models/avatar.glb` if present, and seamlessly fall back to an interactive procedural athletic mannequin if the model file is not yet present.
